# Lakshmi Maddula — Developer Portfolio

React + Vite portfolio with three project case studies and selected screenshots of actual application interfaces.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Project imagery

- BugBox: selected blog, admin and design screens from the SIT782 evidence PDF.
- Food Remedy Co: selected client editing, tag management and dashboard screens from the SIT764 progress reports.
- Ultimate Library: selected application screens from the SIT725 report.

Images have been cropped to emphasize product UI, rather than meeting attendance or academic reporting. Obtain permission before publicly displaying team or client project assets. Review any names, emails, and private information visible within screenshots before deployment.

## Repository links

Only the Ultimate Library frontend repository is linked. Add verified, publicly accessible project repositories to the `links` arrays in `src/main.jsx` if you have permission to share them. Do not link private repositories or imply full ownership of team code.
